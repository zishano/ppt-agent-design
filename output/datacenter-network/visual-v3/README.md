主图使用图像生成工具依据已核查机制绘制并审阅，设备均为概念性示意，不是具体型号照片或机械结构复原。图内文字及部件不是原生可编辑元素，PPT来源页脚可编辑。全部为静态JPEG，无GIF或视频。

assets为最终图片，build.py从这些资产重新生成PPT，无需访问工作区外的原始生成图。依赖python-pptx与Pillow，PDF另用LibreOffice渲染。原始证据复用父目录，身份记录见evidence-manifest.json。
